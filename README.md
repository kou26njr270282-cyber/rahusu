# ポケットわんにゃん

たまごっち風の育成ゲーム。`index.html` をブラウザ（スマホでもOK）で開くだけで遊べます。

## そだてられる どうぶつ
いぬ・ねこ・うさぎ・ハムスター・ペンギン、そして ひみつの パンダ（だれかを おとなまで そだてると でてくる）。
いろは しゅるいごとの いろ＋ファンタジーカラー6しょく、さらに じぶんで すきな いろも えらべます。

それぞれ ほんものに ちかい くらしかた：
- **いぬ**：まいにち さんぽが ひつよう。いかないと ごきげんが さがりやすい
- **ねこ**：きまぐれ。なでても プイッと されることも。おていれは ブラッシング
- **うさぎ**：ごはんは ぼくそう。ぬれるのが にがてなので おふろの かわりに ブラシ。へやんぽで ジャンプ
- **ハムスター**：よるに げんき。おふろは すなあび。まわしぐるまで はしる
- **ペンギン**：みずあびと プールが だいすき
- **パンダ**：たけを たべて、すぐ ねむくなる のんびりや

## ほんものの こうどう（しらべて とりいれたもの）
どうぶつは ときどき ほんものと おなじ こうどうを します。はじめて見た こうどうは「こうどうずかん📖」に まめちしきと いっしょに のこります。
- いぬ：しつけ（おすわり・ふせ・おて）、プレイバウ（あそぼうポーズ）、ズーミー、くびかしげ、あくび（カーミングシグナル）、ブルブル、くんくん、くーん、けいかいぼえ、しっぽフリフリ
- ねこ：ゆっくりまばたき、ふみふみ、ゴロゴロ、しっぽピーン、クラッキング（とりを見て カカカッ）、こうばこずわり、けづくろい、ニャー（おもに 人に むけて なく）
- うさぎ：ビンキー、ごろん（フロップ）、スタンピング、あごスリスリ、たっち、あさゆうの げんきタイム、かおあらい
- ハムスター：ほおぶくろ（体重の約20%）、あなほり、かおくしくし、よるの おさんぽ（ひとばん 5〜9km）、かたまる
- ペンギン：はねづくろい、エクスタティック・ディスプレイ、トボガン、ブルブル
- パンダ：たけを もぐもぐ（1日10〜16じかん）、ひるね、メェ〜と なく、ころりん

きもちは みみと しっぽにも でます（かなしいと みみが たれて しっぽが さがる、びっくりすると みみが たつ など）。
おとは さいしょ オフ。🔊で オンにすると やさしい チャイムだけが なります（どうぶつの なきごえは ふきだしで ひょうじ）。

## ありのままの くらし
- **ゆびで なでる**：ペットを こすると なでられる。すきな ところ・にがてな ところは どうぶつで ちがう（ねこは ほっぺ・あご、いぬは むね、うさぎは おでこ など）
- **ほんとうの さんぽ（いぬ）**：こうえんの みちを あるく。においかぎを まつ・ほかの いぬに あいさつ・うんちを ひろう・ベンチで おみず
- ごはんは じぶんの おさらまで あるいて たべる。ハムスターの まわしぐるま・おふろ・ブラシ・すなあびも 3D

## じぶんで くらす
- のどが かわくと じぶんで みずの おさらへ。おさらに いれた ごはんは おなかが すいたら じぶんで たべる（るすの あいだも）
- つかれると じぶんで ねる（ベッドが あれば ベッドで）。トイレは トイレまで あるいて いく。ボールで ひとりあそびも
- ゆかを タップすると「おいで」で きてくれる（ねこは きぶん しだい）

## おねだりと もくひょう
- **おねだり**：ときどき ペットが「さんぽ！」「ほっぺ なでて」など おねがいを する。20ぷん いないに かなえると ごほうび
- **せいちょうの もくひょう**：こどもに なるまで・おとなに なるまでの やることリスト（🎯）。ぜんぶ たっせいして おとなに なると おうかんの すがたに
- メッセージらんに「つぎに なにを すればいいか」が でる

## あそびかた
- ごはん／あそぶ／おふろ（ブラシ・すなあび）／そうじ／くすり／ねかせる
- あそび：どうぶつごとの とくべつな あそび、「どっちむくかな？」、「おやつキャッチ」
- コインを ためて ショップで たべもの・きせかえ・かぐを かえる
- なかよしレベル、まいにちの ミッション🎯、なまえを よぶ
- へやに おちてる 🎁、まいにちの ログインボーナス、せいかく（5しゅるい）、ずかん

キャラと部屋は three.js の 3D（アニメ調の トゥーン表現・かおは イラストで えがく）で描いています（へやをドラッグすると ぐるっと 見まわせます）。
## ほんとうに そだてるように
- 時間は じっさいの 時計と おなじ。1にちめは あかちゃん、2〜3にちめは こども、4にちめから おとな
- ごはんは 1日 2〜3かい、おみずも かえる。たいじゅうは せいちょうで ふえ、おやつで ぽっちゃり、うんどうで もとに もどる
- トイレの しつけ：トイレで できたら「ほめる」。おぼえるほど ゆかに しなくなる
- どうぶつびょういん：けんこうしんだん・くすり・ワクチン・つめきり
- にっき：その日の おせわと 見せてくれた こうどうを きろく
- きたばかりの ころは きんちょうして ビクッと することも
- **10じかん いじょう なにも おせわを しないと ほねに なって しまう**（ほかの タブ・とじていても おなじ）

データはブラウザ（localStorage）に保存されます。

# わんにゃんカート

マリオカート風の3Dレースゲーム（three.js）。`kart.html` をブラウザで開くだけで遊べます（スマホは横画面推奨・ネット接続が必要）。

- **モード**：🏆グランプリ（4レースのポイント制・トロフィー）/ 🏁VSレース / ⏱️タイムアタック（自分のゴーストと勝負）/ 🎈ふうせんバトル
- **スピード**：50cc / 100cc / 150cc
- **コース4つ**：グリーンサーキット / サンセットハイウェイ（トラックが走る）/ もりのラリー・ナイトグランプリ（大ジャンプ、落ちると戻される）。どのコースにも近道あり（壁の切れ目、コインが目印）
- **オリジナルキャラ8人**＋**マイキャラ作成**
- ダッシュパネル、ジャンプ台（空中でドリフトボタン → トリックで着地ターボ）、コイン（最大10枚で最高速アップ）
- **ドリフト**：曲がりながら長押し → 火花が 青→オレンジ→ピンク と変わり、離すとミニターボ
- **アイテム**：🔥ターボ / 🔥×3 / 🌟ゴールドターボ / ⭐スター / 🌠ながれぼし（自動運転で突進）/ 🍌バナナ / 🍌×3 / 🎁ニセBOX / 🟢バウンドボール / 🟢×3（まわりを回って守る）/ 🚀ロケット / 🎯ねらいうちミサイル / 💣ボム / 🦑スミ / ⚡カミナリ / 👻おばけ（透明になってアイテムを盗む）/ 📯ラッパ（周りのアイテムと相手を吹き飛ばす）
- **アイテムの持ち方**：アイテムボタン長押しでバナナ・ボールなどを後ろに持って守れる。離すと投げる（ブレーキを押しながらだと逆向き）
- **スリップストリーム**（前の車のすぐ後ろで加速）、**グライダー**（大ジャンプ・ばねのあと滑空）、落ちたら**救助ドローン**が戻してくれる

操作：↑/W アクセル、↓/S ブレーキ、←→ ハンドル、Space/Shift ドリフト・トリック、X/Z/Enter アイテム、C うしろを見る、Esc/P ポーズ。
スマホは自動アクセルで、画面ボタンで操作します。

## 開発メモ
- ソースは `kart/src.html`、3Dモデルは `kart/assets/`。`python3 kart/build.py` でモデルを埋め込んだ `kart.html` を生成します。
- 3Dモデル・テクスチャは Kenney の [Starter Kit Racing](https://github.com/KenneyNL/Starter-Kit-Racing) / [Starter Kit 3D Platformer](https://github.com/KenneyNL/Starter-Kit-3D-Platformer) より（CC0）。
