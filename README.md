# 忘却ダンジョン

一度通った道は時間が経つと地図から消え、キャラクターも忘れてしまう一人称ダンジョン。
頼れるのはメモ帳だけ。8番出口のように「異変」を見つけて、0番から8番まで進みます。

`index.html` をブラウザで開くだけで遊べます（ビルド不要）。

## ルール
- 迷宮の形・松明・貼り紙・肖像画・壺の配置は一周のあいだずっと同じ。
- 各階には異変があるかもしれない（0番の階には必ずない）。
- 異変があったと思ったら **上り階段**（スタート地点）で引き返す。
- 異変がなかったと思ったら **下り階段**（迷宮の奥）へ進む。
- 正解なら番号が1つ進み、間違えると0番に戻る。8番を抜ければクリア。
- 歩いた道は数秒で地図から消える。番号の表示も消える。番号が進むほど早く忘れる。
- メモ帳（文字・方眼スケッチ）だけはブラウザに保存され、消えない。

## 操作
| キー | 動作 |
| --- | --- |
| ↑ / W | 前進 |
| ↓ / S | 後退 |
| ← → / A D | 向きを変える |
| E / Space | 階段を使う |

画面下のボタンでも操作できます（スマートフォン対応）。

## 異変の種類（15種）
炎の色 / 消えた松明 / 増えた松明 / 貼り紙の文言 / 肖像画の顔 / 消えた壺 / 動いた壺 /
立っている人影 / 床の足跡 / 壁の目 / 壁の落書き / 増えた通路 / 塞がれた通路 /
下り階段の位置 / 左右反転
