# ポケットわんにゃん

たまごっち風の育成ゲーム。いぬ か ねこ をえらんで、なまえをつけて育てます。
`index.html` をブラウザ（スマホでもOK）で開くだけで遊べます。

## あそびかた
- **ごはん / おやつ**：おなかとごきげんが回復。おやつのたべすぎに注意
- **あそぶ**：「どっちむくかな？」ミニゲーム（5回勝負）
- **おふろ / そうじ**：せいけつを保つ。うんちを放置すると病気になりやすい
- **くすり**：病気のときにあげる
- **ねかせる / おこす**：げんきを回復
- ペットをタップするとなでられます

時間は実際の時計で進みます（30分で1さい）。あかちゃん → こども → おとな と成長し、
おせわミスが少ないと特別なすがたになります。おせわをしないと、たびに出てしまうことも。
データはブラウザ（localStorage）に保存されます。

# わんにゃんカート

マリオカート風の3Dレースゲーム（three.js）。`kart.html` をブラウザで開くだけで遊べます（スマホは横画面推奨・初回はネット接続が必要）。

- 起伏のある立体コース、影つきの3Dカート、どうぶつドライバー（犬・猫・クマ・うさぎ・カエル・パンダ・キツネ・サル）
- キャラ選択はカートを回転台で見ながら選べます

- どうぶつ8キャラ（スピード・かそく・ハンドルの性能がちがう）とCPU7台で3周レース
- コースは3つ：わんわんサーキット / にゃんにゃん砂漠 / こおりの山
- **アイテムボックス**（？）で 🔥ターボ / 🍌バナナ / 🚀ロケット（前のカートを追尾）/ ⭐スター（無敵）
- **ドリフト**：曲がりながら長押し → 火花が 青→オレンジ→ピンク と変わり、離すとミニターボ（長いほど強い）
- 黄色いダッシュパネル、カウントダウン「1」の瞬間にアクセルでロケットスタート
- コースごとのベストタイムを保存

操作：↑/W アクセル、↓/S ブレーキ、←→ ハンドル、Space/Shift ドリフト、X/Z/Enter アイテム、Esc/P ポーズ。
スマホは自動アクセルで、画面ボタンで操作します。
