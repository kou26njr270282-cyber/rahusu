# ポケットわんにゃん

たまごっち風の育成ゲーム。いぬ か ねこ をえらんで、なまえをつけて育てます。
`index.html` をブラウザ（スマホでもOK）で開くだけで遊べます。

## あそびかた
- **ごはん / おやつ**：おなかとごきげんが回復。おやつのたべすぎに注意
- **あそぶ**：「どっちむくかな？」ミニゲーム（5回勝負）
- **おふろ / そうじ**：せいけつを保つ。うんちを放置すると病気になりやすい
- **くすり**：病気のときにあげる
- **ねかせる / おこす**：げんきを回復
- ペットをタップするとなでられます

時間は実際の時計で進みます（30分で1さい）。あかちゃん → こども → おとな と成長し、
おせわミスが少ないと特別なすがたになります。おせわをしないと、たびに出てしまうことも。
データはブラウザ（localStorage）に保存されます。

# わんにゃんカート

マリオカート風の3Dレースゲーム（three.js）。`kart.html` をブラウザで開くだけで遊べます（スマホは横画面推奨・ネット接続が必要）。

- **オリジナルキャラ8人**＋**マイキャラ作成**（どうぶつ・色・ぼうし・アクセ・タイプ・なまえ）
- コース4つ：グリーンサーキット / サンセットシティ / もりのラリー / ナイトグランプリ
- ダッシュパネル、ジャンプ台（空中でドリフトボタン → トリックで着地ターボ）、コイン（最大10枚で最高速アップ）
- **ドリフト**：曲がりながら長押し → 火花が 青→オレンジ→ピンク と変わり、離すとミニターボ
- **アイテム13種**（アイテムBOXから。順位が低いほど強いアイテムが出やすい）
  - 加速系：🔥ターボ / 🔥×3トリプルターボ / 🌟ゴールドターボ（7秒間押し放題）/ ⭐スター（無敵）
  - 妨害系：🍌バナナ / 🎁ニセBOX / 🟢バウンドボール / 🚀ロケット（前の相手を追尾）/ 🎯ねらいうちミサイル（1位を狙う）/ 💣ボム（爆風）/ 🦑スミ（前の相手の画面をかくす）/ ⚡カミナリ（全員スピン＆ちいさく）
  - 防御：🛡️バリア（1回だけ攻撃をふせぐ）

操作：↑/W アクセル、↓/S ブレーキ、←→ ハンドル、Space/Shift ドリフト・トリック、X/Z/Enter アイテム、C うしろを見る、Esc/P ポーズ。
スマホは自動アクセルで、画面ボタンで操作します。

## 開発メモ
- ソースは `kart/src.html`、3Dモデルは `kart/assets/`。`python3 kart/build.py` でモデルを埋め込んだ `kart.html` を生成します。
- 3Dモデル・テクスチャは Kenney の [Starter Kit Racing](https://github.com/KenneyNL/Starter-Kit-Racing) / [Starter Kit 3D Platformer](https://github.com/KenneyNL/Starter-Kit-3D-Platformer) より（CC0）。
