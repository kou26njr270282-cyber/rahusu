# ポケットわんにゃん

たまごっち風の育成ゲーム。いぬ か ねこ をえらんで、なまえをつけて育てます。
`index.html` をブラウザ（スマホでもOK）で開くだけで遊べます。

## あそびかた
- **ごはん / おやつ**：おなかとごきげんが回復。おやつのたべすぎに注意
- **あそぶ**：「どっちむくかな？」ミニゲーム（5回勝負）
- **おふろ / そうじ**：せいけつを保つ。うんちを放置すると病気になりやすい
- **くすり**：病気のときにあげる
- **ねかせる / おこす**：げんきを回復
- ペットをタップするとなでられます

時間は実際の時計で進みます（30分で1さい）。あかちゃん → こども → おとな と成長し、
おせわミスが少ないと特別なすがたになります。おせわをしないと、たびに出てしまうことも。
データはブラウザ（localStorage）に保存されます。

# わんにゃんカート

マリオカート風の3Dレースゲーム（three.js）。`kart.html` をブラウザで開くだけで遊べます（スマホは横画面推奨・初回はネット接続が必要）。

- **オリジナルキャラ8人**：ブレイズ（炎のエースレーサー）、ルナ（ムーンライトアイドル）、ゴンタ（力持ちメカニック）、ピョンコ（電光ダッシュうさぎ）、ケロスケ（さすらいの侍ガエル）、パン博士（天才メカニック博士）、カゲマル（しのびのキツネ）、キャプテン・モン（七つの海の海賊ザル）
- **マイキャラ作成**：どうぶつ・毛の色・服・カート・アクセント色・ぼうし・アクセ・カートタイプ・なまえを自由に組み合わせ
- カートは3タイプ（スポーツ／バギー／クラシック）で性能がちがう
- コース4つ：わんわんサーキット / にゃんにゃん砂漠 / こおりの山 / ほしぞらハイウェイ
- ジャンプ台（空中でドリフトボタンでトリック → 着地ターボ）、コイン（最大10枚で最高速アップ）、ダッシュパネル、障害物
- アイテム：🔥ターボ / 🔥×3 / 🍌バナナ / 🟢バウンドボール / 🚀ロケット / ⭐スター / ⚡カミナリ
- **ドリフト**：曲がりながら長押し → 火花が 青→オレンジ→ピンク と変わり、離すとミニターボ
- コースごとのBGM（ファイナルラップでテンポアップ）、ゴール後は表彰台

操作：↑/W アクセル、↓/S ブレーキ、←→ ハンドル、Space/Shift ドリフト・トリック、X/Z/Enter アイテム、C うしろを見る、Esc/P ポーズ。
スマホは自動アクセルで、画面ボタンで操作します。
