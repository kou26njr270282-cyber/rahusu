# 忘却ダンジョン

一度通った道は時間が経つと地図から消え、キャラクターも忘れてしまう一人称3Dダンジョン。
頼れるのはメモ帳だけ。8番出口のように「異変」を見抜いて、0番から8番まで進みます。

`index.html` をブラウザで開くだけで遊べます（ビルド不要。Three.js r128 を cdnjs から読み込みます）。

## チュートリアル
初めて「はじめから」を押すと、まず図解のルール説明（4枚）が出て、そのあと練習用の小さな迷宮を実際に一周するチュートリアルが始まる。タイトルの「遊び方」からいつでもやり直せる。

1. 光の輪まで歩く → 2. 曲がる → 3. 地図が消えるのを見る → 4. メモ帳に書く →
5. 脇道で鉄扉の番号を読む → 6. 鉄扉を開ける → 7. 下り階段で「進む」 →
8. 2周目、立っている人影に気づいて上り階段で引き返す → 9. 走ってくる人影から逃げ切る → 10. 本番へ

行き先は床の光の輪と、そこまで流れる床の矢印。向きを変える必要があるときは画面端に「→ 右を向く」などが出る。見てほしい画面の部品は光る枠、押すキーは動くキーの絵で示す。できると「✓」が出て次へ進む。

## ルール
- 迷宮の形・松明・貼り紙・肖像画・壺・鉄扉の配置は、一周のあいだずっと同じ。
- 各階に異変があるかもしれない（0番の階には必ずない）。異変は必ず「上り階段→下り階段」の順路上に起きる。
- 異変があったと思ったら **上り階段**（スタート地点）で引き返す。
- なかったと思ったら **下り階段**（迷宮の奥）へ進む。
- 正解なら番号が1つ進み、間違えると0番に戻る。8番を抜ければクリア。
- 順路の途中に **鉄扉** がある。4桁の番号は脇道の真鍮板に刻まれている。**番号も板の場所も、階ごとに変わる。**
- **間違えたり捕まったりすると、迷宮そのものが組み変わる。** 前のメモは役に立たなくなる。
- 異変を見抜くと、次の階で「異変図鑑に記録」と表示される。
- **番号が3つ進むごとに迷宮が1マス広くなる**（最大11×11）。広がった階に異変は出ない。

## 忘れるもの
- 歩いた道：数秒で地図から消える。番号が進むほど早く消える。
- 今の番号：画面上部の表示は4秒で「?」になる。上り階段の看板だけが番号を示す。
- 鉄扉の番号：キャラクターは覚えていない。毎回入力が必要。
- 方角（むずかしい）：向きの表示と地図の矢印が消える。

## メモ帳（ブラウザに保存され、消えない）
- 文字：ワンタップ入力（← → 松明 番号: 今の向き など）
- 地図ノート：9×9の方眼。辺をタップで壁、マスに「上・下・扉・松・壺・絵・紙・番・！」
- スケッチ：手書き

## 難易度
| | 迷宮 | 記憶（0番→7番） | 異変の確率 |
| --- | --- | --- | --- |
| かんたん | 5×5 | 22秒 → 9秒 | 50% |
| ふつう | 7×7 | 16秒 → 6秒 | 55% |
| むずかしい | 9×9 | 11秒 → 3.5秒、方角も忘れる | 60% |

## 画面
- 全画面のゲーム画面。左上に出口の案内表示、左下に消えていく地図、下中央に独り言（字幕）。
- 3D は低解像度で描いてから、色収差・ディザ・粒子・周辺減光で一枚の絵として仕上げる（画質「レトロ」）。
  「くっきり」に切り替えると高解像度で描く。タイトルか一時停止メニューで変更できる。
- メモ帳は Tab（またはメモボタン）で右から引き出す紙のノート。開いている間も時間は進む。

## 雰囲気
- 石の柱、蜘蛛の巣、松明の煤、灯りの中を漂う埃。マウスの位置で少しだけ視線が動く。
- 音は「はじめから」を押すと自動で鳴る（タイトルか一時停止メニューで切れる）。遠くの地鳴り・軋み・足音がときどき聞こえる。
- スタートのすぐ先に、前の探索者が残した紙切れが落ちている。番号が進むごとに書かれていることが変わる。
- 8番出口を抜けると、白い光の中へ出る。

## 操作
| キー | 動作 |
| --- | --- |
| W / ↑ | 前進 |
| S / ↓ | 後退 |
| A D / ← → | 向きを変える |
| Q / E | 横歩き |
| Shift（押しながら移動） | 走る |
| R / X | 振り返る |
| Space / Enter / F | 調べる・階段・扉 |
| Tab | メモ帳を開く・閉じる |
| Esc | 一時停止 |

スマートフォンは画面下のボタンか、視界のスワイプで操作できます。

## 異変（60種）
番号が進むほど、目立つ異変は出にくくなり、見落としやすい異変が出やすくなる。

**危険な異変**：「走ってくる人影」は順路の途中で奥から現れて追ってくる。「迫る闇」は松明が遠くから順に消え、闇が迫る。
「迫る天井」「満ちる水」も同じく時間内に引き返す。「床の穴」に踏み込むと落ちる。
どれも上り階段まで逃げ切れば正解。捕まると0番に戻される（終了画面に「捕まった」回数が出る）。

- 目立つ：**走ってくる人影** / **迫る闇** / **迫る天井** / **満ちる水** / **床の穴** / 吊るされた縄 / 天井の目 / 青い迷宮 / 暴れる炎 / 天井の人影 / 叩かれる扉 / 立っている人影 / ついてくる人影 / 壁の目 / 壁の落書き / 赤い手形 / 赤い灯り / 塞がれた通路 / 見知らぬ扉 / 壁のひび
- ふつう：炎の色 / 消えた炎 / 逆さの貼り紙 / 肖像画の顔 / 消えた壺 / 割れた壺 / 座っている人形 / 濡れた足跡 / 水たまり /
  下り階段の位置 / 左右反転 / 低い天井 / 開いている鉄扉 / 消えた紙切れ / もう一枚の肖像画 / 増えた貼り紙 / 逆さの松明 /
  赤い壁 / 大きな壺 / 奥の灯り / 床の血の跡 / こちらを向く肖像画 / 振り向く人形 / 覗く人影 / 浮かぶ壺 / 消えかける灯り
- 見落としやすい：増えた松明 / 貼り紙の文言 / 肖像画の位置 / 動いた壺 / 増えた通路 / 看板の番号 / 移った松明 /

見抜いた異変は「異変図鑑」に記録されます（難易度ごとの最速記録も表示）。進行状況は階段を使うたびに自動保存され、「つづきから」で再開できます。

## 振り返り
- 異変図鑑で見抜いた異変を選ぶと、その場所に立って3Dで見返せる。「ふだん ⇄ 異変」（T）で切り替えて違いを比べられる。
- 見たエンディングは図鑑からもう一度再生できる。

## エンディング（6種・3Dムービー）
主人公が実際に歩き、カメラが追う映画風のカットシーン。黒帯と字幕つき。
| 名前 | 条件 |
| --- | --- |
| 8番出口 | 8番を抜ける |

| 白紙のメモ | メモ帳を一度も使わずに8番を抜ける |
| 迷宮の一部 | 一周のあいだに5回捕まる |
